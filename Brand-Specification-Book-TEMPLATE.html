How to use this template. Duplicate this file per client, then replace the placeholder frames, hex values and type samples with their real assets.
  • The three core modules belong in every brand bible — logo (including usage rules), color, type.
  • The six optional modules are extras — delete whichever sections a given client didn't scope, and remove their links from the nav above. Strategy and voice usually only apply to clients without an existing strategy document.
  • Dashed boxes are placeholder frames sized to real-world dimensions — drop in the actual logo, mockup, or artwork at that ratio.
  • Every new client needs four things updated on the cover before anything else: the logo (swap the sample logo and favicon for the client's real one), the client name, the date, and the scope line — then keep the date current every time the file is amended after that.
